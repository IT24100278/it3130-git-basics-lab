# IT3130 Git Basics Lab
## Purpose
This repository demonstrates a basic Git workflow for IT3130.
## Files- HelloWorld.html - a small web page used to practise version control- README.md - project documentation
## Commands practised
git init, git status, git add, git diff, git commit, git log, git remote, git push

## What I learned
Staging lets me choose exactly which changes go into the next commit, instead of committing everything automatically. Each commit is a saved snapshot with a clear message describing what changed. A remote (origin) connects my local repository to GitHub, so I can push my commits there and keep a backup.
